# Introduction to the TypeScript Language and the NestJS Framework

> ⚠️ **This repository is not a software project.** There is no application to install, no package to publish, and no code issues to fix: this is **course material**, written for students learning TypeScript and then the NestJS framework.

## 📖 Read the Course

The course can be read online at this address:

**👉 [https://stahe.github.io/en-typescript-nestjs-sept-2026/](https://stahe.github.io/en-typescript-nextjs-sept-2026/)**

No installation is required to read it: a simple browser is all you need.

## 🎯 Who is this course for?

This course is intended for students who have **no prior knowledge** of
TypeScript or NestJS. It starts with the fundamentals of the TypeScript language and gradually moves on to building complete applications with the
, through numerous code examples that are fully commented, line by line.

## 📚 Course Outline

The course is organized into major sections:

1. **The Fundamentals of TypeScript** — setting up the development environment,
   language syntax, static typing, object-oriented programming.
2. **TypeScript HTTP Functions** — building an HTTP server and an HTTP client
   in pure TypeScript, before introducing any framework.
3. **Database Access** — a comparison of three approaches: the native
   `mysql2`, the [TypeORM](https://typeorm.io/) ORM, and the [Prisma](https://www.prisma.io/) ORM.
4. **The NestJS Framework** — introduction to the framework, its MVC architecture,
   request handling (actions/responses), the model layer, and data access
   with NestJS.
5. **A comprehensive case study** — porting an income tax calculation server, originally written in PHP, to NestJS: controllers, DAO and
   business logic layers, session management, and building HTML pages with EJS templates.
